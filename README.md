# Broke No More — Student Budget Tracker

## About the Project
Broke No More is a personal budget tracking application designed to help students manage their money, track income and expenses, and make better spending decisions.

## Features
- Add and track income.
- Record and manage expenses.
- View current balance and spending summaries.
- Set and track a monthly budget.
- View spending analytics.
- Check whether a purchase is affordable.
- Use a no-spend challenge.
- Download transaction records as a CSV file.
- Store transaction data using SQLite.

## Technologies Used
- Python — application logic
- Streamlit — user interface
- Pandas — data handling
- Plotly — charts and visualizations
- SQLite — database storage

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal in the project folder.
4. Install the required libraries:

   `python -m pip install -r requirements.txt`

5. Start the application:

   `python -m streamlit run app.py`

6. Open the local URL displayed in the terminal.

## Project Goal
The goal of Broke No More is to help students understand their spending habits, plan a monthly budget, and manage their finances more responsibly.
